# Literature Skill V0 Activation Cases

## Should activate

1. “Find the latest studies on urban heat exposure and verify the DOIs.”
2. “Analyze these papers and create evidence-linked notes.”
3. “Does this citation support the causal claim in this sentence?”
4. “Search my Zotero library for papers on park accessibility.”
5. “Extract the methods and data needed to reproduce this paper.”

## Should not be the primary skill

1. “Fit a spatial regression to this CSV” -> data-analysis workflow.
2. “Rewrite this already sourced abstract” -> manuscript/writing workflow.
3. “Create a GitHub branch” -> Git workflow.

## Incomplete-input behavior

- A broad review request should establish scope and output without demanding unnecessary questions.
- A citation audit without source text should search or report `FULL_TEXT_MISSING`.
- A Zotero import request should stop at explicit write authorization if not already granted.
