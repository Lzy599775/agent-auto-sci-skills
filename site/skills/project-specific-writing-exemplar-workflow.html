Private manuscript exemplar lifecycle

project-specific-writing-exemplar-workflow

为单篇稿件建立隔离的 exemplar profile、Master 20 和 Core 3 作者审批门，用于实质性写作、结构重写和目标期刊适配。

适合什么时候用

实质性写作与大修

当 Introduction、Methods、Results、Discussion、Abstract 或整体稿件需要重写时使用。

期刊近邻对标

当需要从功能近邻论文学习论证结构、证据链和段落功能，而不是复制语言时使用。

典型输入

使用 project-specific-writing-exemplar-workflow，为 MANUSCRIPT_ID=urban-green-exposure-01 建立私有 exemplar profile，先提出 Master 20 和 Core 3，等待作者审批后再进入 Discussion 重写。

生命周期

S0_UNINITIALIZED -> S1_MANUSCRIPT_PROFILED -> S2_CANDIDATE_POOL_READY -> S3_MASTER_20_SELECTED -> S4_CORE_3_PENDING_AUTHOR_APPROVAL -> S5_CORE_3_APPROVED -> S8_ACTIVE_FOR_WRITING

Core 3 审批是唯一作者 gate。审批前不得进行段落、句子或词频分析，也不得修改稿件。

边界

项目状态、稿件事实、论文库和审批记录必须保存在对应项目的私有状态中，不得跨项目继承。禁止保存长段来源原文、独特措辞、citation chain、因果解释或超出自有证据的结果逻辑。
