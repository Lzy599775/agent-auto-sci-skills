# Research Project Bootstrap

Copy this structure only after auditing a new or under-structured research repository. Do not impose it on mature repositories automatically.

Suggested files:

- `AGENTS.md`
- `README.md`
- `docs/project_context.md`
- `docs/research_questions.md`
- `docs/data_inventory.md`
- `docs/methods.md`
- `docs/decision_log.md`

Replace placeholders with project-specific, evidence-supported content.
