# Research Vault

The Research Vault stores **derived scientific knowledge**, not original bibliographic assets.

## Responsibilities

| Area | Content |
|---|---|
| `literature/` | Structured paper notes and corpus-level observations |
| `concepts/` | Definitions, constructs, mechanisms, and competing interpretations |
| `methods/` | Method records, comparisons, assumptions, and validation notes |
| `datasets/` | Dataset provenance and suitability records |
| `evidence/` | Claim-level evidence records |
| `synthesis/` | Cross-source synthesis and evidence-gap maps |
| `projects/` | Project-specific derived reasoning and links to project repositories |

## Boundary with Zotero

Zotero remains the source of truth for bibliographic parent metadata, citation keys, attachments, PDFs, and indexed full text. Vault records should reference Zotero item keys, citation keys, DOIs, or other authoritative identifiers.

Do not duplicate PDFs here by default. Do not treat a vault summary as equivalent to the original paper.

## Public repository rule

This repository is public. Store only non-sensitive templates or derived records explicitly suitable for publication. Keep restricted data, private PDFs, unpublished manuscripts, confidential reviews, and personal paths outside this repository.
