# Source Hierarchy

## Scientific literature

1. Original article, preprint, report, supplement, table, figure, or dataset documentation.
2. Publisher, DOI registration agency, bibliographic database, or official repository metadata.
3. Verified structured extraction tied to source locations.
4. Review articles and high-quality secondary synthesis.
5. Discovery-only summaries, snippets, and search results.

Use lower-ranked sources for discovery, not as substitutes when the original is available.

## Software and tools

1. Current official documentation.
2. Official repository, release notes, and source code.
3. Maintainer-authored examples.
4. Well-maintained community material.

## Datasets

1. Official provider, catalog, DOI record, or repository.
2. Versioned data documentation and license.
3. Project-maintained provenance record.
4. Secondary descriptions.

## Local projects

1. Preserved raw source.
2. Validated processed data generated by documented scripts.
3. Analytical data and model outputs.
4. Figures, tables, and narrative interpretation.

## Conflict handling

- Prefer the higher-ranked and more current authoritative source.
- Record `CONFLICTING_EVIDENCE` when disagreement remains material.
- Do not silently reconcile incompatible definitions or values.
- Escalate when the conflict changes the scientific conclusion or method choice.
