# ACADEMIC_WRITING_PROFILE_V2 compatibility entry

This file is retained as a compatibility path for existing Codex and ChatGPT routers. It is not an independently maintained profile and contains no separate style rules.

The sole authority is `DEFAULT_ACADEMIC_WRITING_PREFERENCES` in [the Academic Writing Exemplar Protocol](../../skills/agent-auto-sci-scicomm/references/academic_writing_exemplar_protocol.md#default-academic-writing-preferences). All clients and writing routes must resolve the contract there. Updates belong only in that authority; this file must remain a pointer.

Compatibility markers (inherited, not independently configurable): `CLAIM_FIRST_PROSE`, `DIRECT_RESULT_REPORTING`, `EVIDENCE_LED_EXPLANATION`, `NATURAL_SENTENCE_VARIATION`, `LOW_TEMPLATE_DENSITY`, contrast-overuse review, paragraph-rhythm review, and preservation of negative results. Sentence quotas and mechanical replacement remain prohibited by the authority.
