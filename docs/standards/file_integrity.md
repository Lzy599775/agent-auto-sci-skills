# File Integrity Standard

## Protect originals

- Preserve raw data, source PDFs, submitted manuscripts, signed documents, and other irreplaceable sources.
- Prefer derived files in approved output or working directories.
- Audit existing repository structure before adding or moving files.

## Public-repository boundary

Do not commit credentials, tokens, cookies, private PDFs, restricted datasets, unpublished manuscripts, confidential reviews, personal absolute paths, or unlicensed third-party content.

## Write scope

- Modify only files required by the task.
- Inspect existing user changes before editing overlapping paths.
- Stop before overwriting irreplaceable or ambiguous material.
- Use reversible operations where practical.
- Report material deletion and recovery status if deletion was explicitly authorized.
