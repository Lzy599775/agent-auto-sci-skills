# Figure Workflow

## Procedure

1. State the claim or decision the figure must support.
2. Inspect the analytical dataset, unit, uncertainty, grouping, scale, and missingness.
3. Select a chart, map, or table appropriate to the data-generating process and comparison.
4. Preserve units, sample sizes, uncertainty, and meaningful reference points.
5. Avoid misleading axes, area/volume encodings, unreported smoothing, and inaccessible color choices.
6. Generate from reproducible code and documented inputs.
7. Validate plotted values against source summaries.
8. Audit title, caption, legend, labels, ordering, resolution, font size, color accessibility, and export format.
9. Keep interpretation in the caption bounded to what is displayed.

## Outputs

- Figure intent and design choice.
- Reproducible figure code.
- Exported asset and caption.
- Data-to-figure validation result.
